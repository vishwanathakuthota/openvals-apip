# APIP Engineering Rules

Always read docs/PRD.md before implementing.

Never create mock implementations.

Never leave TODO placeholders.

Every feature must be deployable.

Every API must have tests.

Every metric must support Confidence Score Engine.

Every dashboard widget must display:

- Source Count
- Confidence Score
- Last Updated

All code must run through Docker Compose.

All pull requests must update documentation.

Do not introduce technologies outside the approved stack without justification.
