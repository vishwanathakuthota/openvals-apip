# OpenVals Score

OpenVals Score measures whether a metric has enough trusted, transparent, reproducible evidence to be published with confidence.

## Formula

```text
OpenVals Score =
Confidence * 30%
+ Evidence Coverage * 25%
+ Transparency * 20%
+ Reproducibility * 15%
+ Source Quality * 10%
```

## Components

| Component | Weight | Meaning |
| --- | ---: | --- |
| Confidence | 30% | Confidence Engine output from reliability, freshness, verification, and methodology. |
| Evidence Coverage | 25% | Required evidence found divided by required evidence expected. |
| Transparency | 20% | Methodology clarity and explanatory completeness. |
| Reproducibility | 15% | Whether the collection method and calculation can be repeated. |
| Source Quality | 10% | Source credibility score from source tier, reliability, and freshness. |

## Classifications

| Score | Classification |
| --- | --- |
| 90-100 | Exceptional |
| 80-89 | Strong |
| 70-79 | Reliable |
| 60-69 | Moderate |
| <60 | Weak |

## Publishing Rule

OpenVals Score does not publish data by itself. Only records with human reviewer approval can be published by the Publisher Agent.
