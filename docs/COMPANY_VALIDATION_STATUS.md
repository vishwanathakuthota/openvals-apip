## Scoring Requirements

Every published metric for the ten-company set includes:

- Value
- Confidence Score
- Confidence label
- Evidence Coverage Score
- OpenVals Score
- Trust Index contribution
- Source count
- Last updated timestamp
- Methodology note
- Source lineage

## Validation Requirements

Each company is considered validated when all six required metric keys have:

- Published status
- Validated evidence classification
- Source URL
- Confidence score greater than zero
- Evidence coverage score greater than zero
- OpenVals Score greater than zero
- Reviewer approval timestamp
- Publisher timestamp
